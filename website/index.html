What it actually saves

Most "session restore" tools reopen your apps. Stash reopens your work — the project you had open, the folder your terminal was in, the tabs you were reading.

🗂️ Window layout

Every window's position and size, stored as a fraction of its monitor — so a layout captured on a 4K desktop restores sensibly on a laptop.

📘 VS Code projects

Reopens the actual project folder, not a blank editor. Two windows on two different projects come back as two windows.

⌨️ Terminal directories

Your shell reopens in the directory it was working in, instead of dumping you back at your home folder.

🌐 Browser tabs

With the companion extension, every tab, pinned tab and tab group comes back — and restored background tabs stay unloaded, so they cost no memory.

📋 Templates

Define a set of apps once — "frontend work", "code review" — and launch that arrangement whenever you switch context.

🔒 Entirely local

No account, no cloud, no telemetry. Everything lives in one JSON file on your machine and nothing is sent anywhere.

Browser tabs need the extension

No operating system exposes browser tabs to other applications — so without the companion extension, Stash can tell that Chrome was open but not what was in it. Everything else works either way.

  1. Install Stash Bridge from the Chrome Web Store.
  2. Open Stash and click Browser in the header.
  3. Copy the pairing token and paste it into the extension's settings.

The extension talks only to 127.0.0.1 on your own machine, never captures incognito windows, and sends nothing to the internet. Read the privacy policy.
