Privacy Policy

Applies to the Stash desktop application and the Stash Bridge browser extension. Last updated 9 August 2026.

The short version

Stash collects nothing, transmits nothing, and has no servers. All data stays on your computer. There is no account, no analytics, no telemetry, and no crash reporting. Neither the app nor the extension makes a single request to the internet.

What the desktop app stores

Stash saves your workspaces to a single workspaces.json file inside your operating system's application-data folder. It contains:

  • names you give your workspaces and templates, and any tags you add
  • the file path, window title, position and size of each captured application
  • for VS Code windows, the project folder path
  • for terminal windows, the working directory
  • for browser windows, the tab and tab-group information described below

This file never leaves your machine. You can read, edit, back up or delete it at any time. Deleting it erases everything Stash knows.

What the browser extension accesses

Stash Bridge exists for one purpose: to let the Stash desktop app save and restore your browser windows. To do that it reads, from non-incognito windows only:

  • window position, size and state
  • tab URLs and page titles, plus whether a tab is pinned or active
  • tab group names, colours and collapsed state

Where that information goes

Only to the Stash application running on the same computer, over a loopback connection to 127.0.0.1. Loopback traffic never leaves the device — it is not routed to any network. The extension declares no other host permissions, so it is technically incapable of sending your data anywhere else.

The connection is protected by a pairing token you copy from Stash into the extension, which prevents other software on your computer from requesting your tab list.

What is never collected

  • Incognito and private windows — excluded entirely
  • page contents, cookies, passwords, form data or browsing history
  • personal or device identifiers of any kind
  • usage analytics or telemetry

Third parties

There are none. No data is sold, shared, or transferred to anyone, because no data is ever collected in the first place.

Changes
